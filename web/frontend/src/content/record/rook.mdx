The rook is the wall: solid, dependable, the structure everything else leans on. This
chapter is about the infrastructure that keeps the engine honest — because an engine is
only as good as the tests that measure it.

## Proving it plays

It covers the **UCI protocol** that lets any GUI or match runner drive the engine, the
**automated harness** that pits engines against each other, **Elo benchmarking** with
confidence intervals, and **Average Centipawn Loss (ACL)** measured against a localized
Stockfish to score move quality by game phase.
